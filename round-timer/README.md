# Reveal Timer

A countdown that uncovers a picture as time runs out. No build step.

| File | What's in it |
|---|---|
| `index.html`, `style.css` | Markup and styles |
| `art/` | The drawings: `fn(ctx, S)` paints a square of side `S`. `openmoji.js` is generated by `scripts/build_openmoji.py` |
| `catalog.js` | Everything there is to reveal, by category |
| `storage.js`, `collection.js` | What's saved (and old save formats); what's been found and what comes next |
| `reveals.js`, `celebrations.js` | How the picture is uncovered; the effects at the end |
| `audio.js`, `wakelock.js` | The chime; keeping the screen on |
| `dom.js`, `sheet.js`, `app.js` | Helpers; the collection sheet; the setup screen and timer |
| `sw.js` | Opens without a network after one visit |
| `scripts/shots.mjs` | Renders drawings to PNG, optionally against an older revision |

- **iOS 9.3 is the floor.** Scripts are ES5, loaded with plain `<script>` tags that share the `RT` global. `tests/legacy.spec.mjs` checks an approximation; a real device is the real test.
- **A new file** goes in `index.html` and in the list in `sw.js`. A test checks that they agree.
- **Never rename the `localStorage` keys** in `storage.js`: they hold people's collections.
